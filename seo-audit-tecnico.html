Audit tecnico SEO — Novarium.net

Rigenerato dagli appunti il 12/10/2026.

Sito: Next.js, multilingua (en/it/fr/es/de) · Sitemap: 158.550 URL (31.666 prodotti × 5 lingue; sonde 2.068/lingua, parts 7.274/lingua)

Criticità (in ordine di impatto)

  1. Paginazione solo JavaScript — ~8 link per pagina brand; i ~31k prodotti/lingua sono raggiungibili praticamente solo via sitemap → prodotti orfani, crawl budget sprecato, indicizzazione ~1% sulle sonde (112/10.340 URL con impressioni in 6 mesi).
  2. ~25 varianti URL per prodotto (5 prefissi lingua × 5 slug lingua), incluse combo ibride tipo /en/products/sondes-ecographiques/... (prefisso EN + slug FR) → diluizione, "Crawled — currently not indexed".
  3. Zero hreflang — 5 versioni lingua competono/duplicano senza segnali.
  4. Duplicato www/non-www completo — non-www risponde 200 invece di 301; 27% delle impressioni su host non-www a pos. media peggiore (11,6 vs 6,6).
  5. Legacy /vendita/prodotto/?pid=N → 404; legacy /vendita/marca/ → 301 verso ricerca interna noindex (42% del traffico Parts poggia lì → a rischio).
  6. Redirect ?lang= legacy che atterrano sulla lingua sbagliata.
  7. Product snippet invalido ("1 invalid item" in GSC): manca un campo (offers/review) → niente rich results in SERP.
  8. Template prodotto thin: title/H1 senza tipo + macchina → Google mostra sibling sbagliati per query "marca+modello".

Punti positivi

  • Nuova struttura /products/ultrasound-probes/... e /products/ultrasound-parts/... SEO-friendly (ma ancora invisibile a Google: 0/80 nei brand test).
  • Sitemap completa e aggiornata.

Verifiche consigliate post-fix

  • URL Inspection su campione sonde/parts per lingua
  • GSC → Indicizzazione → Pagine (trend indicizzate)
  • Re-test 80 query brand (baseline 10/10: nuovo formato 0/80)
  • Rich Results Test su pagina prodotto
